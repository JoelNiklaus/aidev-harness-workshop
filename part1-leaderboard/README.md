# Part 1: build a harness leaderboard

Setup and the four challenges are in the [main README](../README.md). Start your coding agent in this folder.

| File | What it is |
|---|---|
| `AGENTS.md`, `CLAUDE.md` | the facts and guard rails your coding agent reads when it starts in this folder |
| `sample-results.json` | made-up results the page starts with (mock data) |
| `index.html` | written by your coding agent: your leaderboard page |
| `results.json` | written by `aidev-lb run`: your measured results |
| `docs/` | how the run works, the results format, and the audit idea for after the session |
| `hints/` | only if you are stuck: sample requests and one finished page |
