Part 2: evolve the harness

Your coding agent proposes patches to a small agent; a job on Hugging Face scores each one, and the loop keeps a patch only if it wins on tasks your coding agent never saw. One run takes about 20 minutes.

What you need

  • A Hugging Face account with credits. The session coupon adds $10 of credits, which covers one run; the coupon link is on the slide and in the prep email. Open it while logged in.
  • uv (step 1) and a Hugging Face token (step 2), as in Part 1.
  • A paid Claude plan that includes Claude Code, or a paid ChatGPT plan that includes Codex. Your coding agent runs on your own plan (step 3).
  • A laptop that stays open during the run.

1Install uv

macOS and Linux

curl -LsSf https://astral.sh/uv/install.sh | sh

Windows (PowerShell)

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

2Get a Hugging Face token

At huggingface.co/settings/tokens, create a token with the permissions Make calls to Inference Providers and Start and manage Jobs (a write token also works). Then log in and paste it:

uvx hf auth login

3Install your coding agent

Skip this step if Claude Code or Codex already runs on your laptop and is logged in.

Claude Code, macOS and Linux. Then run claude and log in.

curl -fsSL https://claude.ai/install.sh | bash

Codex, macOS and Linux. Then run codex login.

curl -fsSL https://chatgpt.com/codex/install.sh | sh

On Windows, use the PowerShell installer for Claude Code or Codex.

If something fails

  • uvx: command not found: open a new terminal window after installing, so it picks up the new command.
  • claude or codex: command not found: open a new terminal window after installing the coding agent.
  • "Not logged in" from claude, or 401 from codex: run claude and type /login, or run codex login.
  • "no credits" or 402: open the coupon link while logged in to Hugging Face; the coupon link is on the slide and in the prep email.
  • 401 or 403: the token lacks a permission. Create a new one with both permissions from step 2 and run uvx hf auth login again.
  • "No Hugging Face token found": run uvx hf auth login and paste your token.
  • Timeouts or SSL errors: a company VPN or proxy may block the calls. Turn the VPN off or use another network, for example your phone's hotspot.
