Part 1: join the swarm

Your coding agent starts one job on Hugging Face that runs trials for the shared board on the projector. Your laptop can close afterwards.

Live board

What you need

  • A Hugging Face account with credits. Sign up for free at huggingface.co/join. The session coupon adds $10 of credits; the coupon link is on the slide and in the prep email. Open it while logged in.
  • uv (step 1) and a Hugging Face token (step 2).
  • A laptop with a terminal. No Docker, no GPU, no repo to clone.

1Install uv

macOS and Linux

curl -LsSf https://astral.sh/uv/install.sh | sh

Windows (PowerShell)

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

2Get a Hugging Face token

At huggingface.co/settings/tokens, create a token with the permissions Make calls to Inference Providers and Start and manage Jobs (a write token also works). Then log in and paste it:

uvx hf auth login

3Check your setup

This makes one GLM-5.3-Flash call, runs one tiny Hugging Face Job and one command in a Hugging Face Sandbox. It takes 15 to 35 seconds, costs well under one cent and claims no workshop task.

uvx --from "https://github.com/JoelNiklaus/aidev-harness-workshop/releases/download/swarm-v0.4.3/aidev_swarm-0.4.3-py3-none-any.whl" aidev-swarm check

The last line reads

[aidev-swarm HH:MM:SS] ready: <you> can call the workshop model, run HF Jobs and use HF Sandboxes. See you at the workshop.

4Start your Job

Paste this into your coding agent. Claude Code, Codex, Cursor or any agent that can run shell commands:

Run `uvx --from "https://github.com/JoelNiklaus/aidev-harness-workshop/releases/download/swarm-v0.4.3/aidev_swarm-0.4.3-py3-none-any.whl" aidev-swarm launch` in a terminal. It starts one Hugging Face Job under my HF account that claims Terminal-Bench 2.1 trials from the workshop's shared grid, runs each in an HF Sandbox and submits the results to the live board; the command returns in a few seconds. Tell me the Job page and the board URL it prints. Then follow the Job with `uvx hf jobs logs -f <job id>` and, each time a line says PASS or FAIL, tell me the harness, the task, the cost and the time in one line. If `launch` stops with an error, read it and fix only my local setup (HF login with `uvx hf auth login`, credits, uv), then start it again; never edit the tool's code and never print my token. If the Job log says "stopping: 3 trials in a row failed", show me its last error lines and run `launch` once more. When I ask why a trial failed, explain in three lines whether the model, the harness or the task is the likely cause.

Or run it yourself in a terminal

uvx --from "https://github.com/JoelNiklaus/aidev-harness-workshop/releases/download/swarm-v0.4.3/aidev_swarm-0.4.3-py3-none-any.whl" aidev-swarm launch

You are in when you see this

[aidev-swarm HH:MM:SS] launched HF Job <job id> in <you>'s namespace: it runs trials until the grid is full, up to 8 at once on Hugging Face. You can close the laptop.
  Job page: https://huggingface.co/jobs/<you>/<job id>
  Logs:     uvx hf jobs logs -f <job id>
  Stop:     uvx hf jobs cancel <job id>
  Board:    https://agent-harness-workshop-aidev-swarm.hf.space

The command returns in a few seconds and the Job keeps running on Hugging Face. Each finished trial appears on the board.

Open the live board

If something fails

  • uvx: command not found: open a new terminal window after installing, so it picks up the new command.
  • "no credits" or 402: open the coupon link while logged in to Hugging Face; the coupon link is on the slide and in the prep email.
  • 401 or 403: the token lacks a permission. Create a new one with both permissions from step 2 and run uvx hf auth login again.
  • "No Hugging Face token found": run uvx hf auth login and paste your token.
  • Timeouts or SSL errors: a company VPN or proxy may block the calls. Turn the VPN off or use another network, for example your phone's hotspot.
